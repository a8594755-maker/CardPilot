# ASSET-AUDIT-001 — Full-200bb compatibility audit

Status: `COMPLETED_REPORTING_ONLY`  
Decision: `NO_COMPATIBLE_FULL_200BB_ASSET`

This audit asks a strict route-pivot question: is there an existing artifact that already
plays complete 200bb HUNL from preflop through river, uses the AlphaHoldem v55
observation and current `9slot_v5` action contract, and loads through the current
full-hand Slumbot adapter? The answer is no. This is not a strength evaluation and
does not authorize a trainer change.

| Candidate | What exists | Blocking incompatibility |
| --- | --- | --- |
| BC v3 anchor | 200bb AlphaHoldem-shaped nine-output checkpoint | metadata is `v4` / `9slot_v4`; scripted/legacy teacher; no v55 contract proof |
| SD-CFR HUNL v1/v2 | loadable advantage checkpoints | inspected checkpoints are `srp_50bb`; distinct 56-D encoder; no full-hand adapter |
| 200bb CFR export | 96 board policy exports plus 96 metadata files | `HU_NLHE_SRP` postflop only; no preflop/non-SRP coverage; not a v55 checkpoint |
| V10 | 54-D postflop value network and Slumbot harness | harness supplies hand-written preflop; 3-action/5-sizing heads are not `9slot_v5` |

Key artifact hashes are recorded in
`reports/v5_asset_audit_001_20260710.json`. The 200bb SRP metadata explicitly
declares `HU_NLHE_SRP`; the SD-CFR checkpoints declare `srp_50bb`; the BC
checkpoint declares `env_version=v4`, `obs_version=v4`, and
`action_space_version=9slot_v4`.

Therefore `route_pivot_exp_w2_eligible=false` and
`exp_w2_registration_authorized_now=false`. Building an adapter, relabeling a
teacher, or filling missing game coverage would be a new registered experiment,
not evidence that W2 is presently available.
