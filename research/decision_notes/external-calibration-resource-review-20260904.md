# Bounded resource review during fixed external evaluation

Read-only review on2026-09-04, while the original Seed1 4M fresh20k sessions run. No external results were inspected for this note; no downloads, installs, paid calls, new training or changes to the live policy. Attach to the existing calibration record after its owner is terminal.

## Immediate allocation context

The current static-KL family has uncertain4M internal improvement, little drift from Standard10, and newly qualified multi8 wall-throughput. External calibration remains the next deciding observation. Check whether a readily usable stronger public policy or teacher would materially lower expected research cost before committing to another large local allocation.

## Public resources checked

- DecisionHoldem's official repository describes a CFR blueprint plus real-time search, and reports an old roughly20k-hand Slumbot result above730mbb/hand. Required blueprint/cluster files are distributed separately through Baidu; the documented development machine has512GB RAM, and some components are supplied only as compiled binaries. This is not a ready local neural checkpoint or a freshly replicated100k result. Its blueprint could merit a separately bounded access/size/portability/teacher-quality feasibility check if needed, but this review did not verify asset availability, runtime memory requirements or current strength. No binaries were executed. [Official repository](https://github.com/AI-Decision/DecisionHoldem).

- PokerLlama-4 provides8B weights and reports strong offline action-type accuracy but negative live results against two other language-model policies, with a discretized live bet space. Its model card does not establish our Slumbot criterion. I would not replace the current main line with it based on action-label accuracy. Also, the card's suggestion that greedifying a mixed equilibrium is approximately Nash is not a general guarantee: deterministic argmax can destroy equilibrium mixing. [Author model card](https://huggingface.co/jevonmao/llama31-8b-poker-mix-v1-step10k).

- The related HoldemMix corpus is a200bb teacher-data candidate, but its card describes single sampled strategy labels, incomplete rationale auditing, and research/noncommercial terms. Access to additional GTO Wizard API collection requires a separate agreement. It is not an unrestricted ready-made source of proven stronger on-policy targets; no data were downloaded or license assumptions made. [Author dataset card](https://huggingface.co/datasets/jevonmao/poker-sft-mix-v1).

- PokerSkill is a human-rule-guided frontier-LLM framework, not a released locally trained poker-weight solution. The paper evaluates against GTO Wizard using AIVAT and explicitly cites inference cost constraints. A better score against a common opponent does not establish head-to-head Slumbot superiority, and its reported variance-reduced intervals are not our raw-hand acceptance test. A paid LLM evaluation path is not authorized by the unanswered compute-budget question. No switch to this approach or copied action-rule patch is justified here. [Author paper, method and evaluation appendix](https://arxiv.org/html/2605.30094v1).

## Local history prevents relabeling old ideas

`v6-low-temperature-65k-pilot-20260901` already compared hero/PPO T0.5 against T1: pooled delta-0.42265 CI[-19.30154,18.45624], with significantly negative Standard10 anchor delta-27.07398 CI[-52.68909,-1.45886]. `v6-source-kl-temperature-65k-greedy-fresh5k-slumbot-20260901` changed the reference-KL temperature, not hero behavior, and its frozen external pilot was-142.7232 CI[-200.6425,-84.8039]. Neither is a new untested execution-temperature trick; their different contracts and small scales should still be distinguished.

The old moving-reference interval1 pilot is similarly not a faithful long-inner-phase NashPG replication. A properly phased learning control remains a candidate, not a predetermined winner. Do not start many new smokes while waiting or interpret current small drift as evidence that stronger policy learning is impossible.

## Decision

This bounded search did not establish a ready, contract-compatible, stronger downloadable model that warrants interrupting the current plan. It did identify a possible teacher-resource lead, which remains unverified and does not restore the old single-imitation-teacher route. First complete the fixed external calibration; then choose between one substantive learned-method control and continued scale using external evidence and measured cost. Keep the existing generally learned-policy objective and all final blind-test requirements unchanged.
